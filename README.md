# Projects

## Task 1 — Loan Approval Prediction

### Objective

Build a supervised machine learning model capable of predicting whether a loan application should be approved based on applicant information.

### Skills Applied

- Data Cleaning
- Missing Value Imputation
- Feature Engineering
- Class Imbalance Handling (SMOTE)
- Classification Models
- Model Evaluation
- Business Interpretation

### Algorithms

- Logistic Regression
- Decision Tree
- Random Forest

### Highlights

- Compared four classification models.
- Achieved best performance using Logistic Regression.
- Evaluated using Precision, Recall, F1 Score and ROC-AUC.
- Identified important factors influencing loan approval.

📁 **Project Folder:** `Task 1 - Loan Approval Prediction`

# How to Run

Clone this repository:

```bash
git clone https://github.com/piyushrai956/Alfido-Tech-Internship.git
```

Move into the repository:

```bash
cd Alfido-Tech-Internship
```

Install dependencies:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn wordcloud imbalanced-learn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook corresponding to the project you wish to explore.
